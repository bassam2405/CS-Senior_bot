This is a chatbot especially made for cs students to improve their skills.    
It also have a savage persona but expect user to learn easy things very fast and move to real stuff.   
GUI is not allowed, but we still try to make the response window not look boring to user.   
We have also tried to gamify it by using warning and reputation score.  
We were facing issue that daily limit of request was finishing very fast , So we added the API KEY option so that user can give their API KEY and get their query resolved.
